# Liquidity Vision 
**ML-powered cash flow forecasting system.**

## Overview
[cite_start]This project solves the problem of manual cash flow tracking[cite: 307]. [cite_start]It predicts the next 6 months of liquidity using Machine Learning (Prophet/Linear Regression) and alerts managers when cash runs low[cite: 304, 372].

## Tech Stack
- [cite_start]**Backend:** Python (Flask, Pandas, Scikit-learn, Prophet)[cite: 291, 311].
- [cite_start]**Frontend:** HTML5, CSS3, JavaScript (Chart.js)[cite: 291, 555, 556].

## How to Run
1. [cite_start]Install dependencies: `pip install -r requirements.txt`.
2. [cite_start]Run the backend: `python backend/app.py`.
3. [cite_start]Open `frontend/index.html` in your browser.
